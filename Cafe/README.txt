BAROAK Noida — Frontend Website
================================
Open index.html in a browser.

Files:
- index.html  : page structure/content
- style.css   : responsive premium visual design
- script.js   : mobile menu + scroll reveal

This is a frontend-only website. No backend or database is required.

Important:
The website uses publicly indexed image URLs and links to live Zomato/Dineout/Instagram pages for the complete gallery, current menu and booking. Third-party ratings, hours, prices and offers can change, so the live listing links are intentionally included.
